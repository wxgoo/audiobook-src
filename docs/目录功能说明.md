# 「目录」功能说明（多层分类）

> 版本：4.6.0-15
> 对应配置项：`ENABLE_FOLDER_BROWSE`
> 对应 calibre 自定义列：`#folder`

## 一句话

「目录」是书库的**二级分类系统**，和「类别」（calibre 的 tags）不是一回事：
类别是一本书可以有很多个并列标签；目录是**一条路径**，最多两级，
用来在侧栏像文件夹一样逐层浏览。

## 三个地方出现，各自职责

### 1. 总开关（决定功能是否存在）

**管理 → 系统设置 → 扩展功能 → ☑「启用以目录进行多层分类的功能」**

配置项 `ENABLE_FOLDER_BROWSE`，默认 `false`。

关掉时：

- 侧栏不显示「目录」
- 书详情页不显示橙色的「目录 : 未设置」标签
- `/folder` 页面直接 404
- OPDS 里的目录浏览也关闭

**这是真正的功能开关**，改完要重启 tornado（`docker exec audiobook-mybooks-1 supervisorctl restart mybooks:tornado`）。

### 2. 侧边栏显示项目（只管入口显不显示）

**管理 → 系统设置 → 侧边栏显示项目 → ☑「目录」**

这一栏（还有「有声书 / 丛书 / 阅读书单」）只是控制**侧栏里那个入口按钮显不显示**，
不影响功能本身。也就是说：

| 总开关 | 侧栏勾选 | 结果 |
|---|---|---|
| 开 | 勾 | 侧栏有「目录」，可正常用 |
| 开 | 不勾 | 侧栏没入口，但书详情页仍能编辑目录，直接访问 `/folder` 仍可用 |
| 关 | 勾 | 侧栏仍不显示（功能被总开关关掉了）——勾选被忽略 |

### 3. 书详情页的橙色标签「目录 : 未设置」

这是给**单本书设置目录**的地方，点标签 → 输入路径 → 保存。

## 格式规则

`一级.二级`，中间用英文句点分隔。

| 规则 | 说明 |
|---|---|
| 最多 2 级 | `小说.科幻` 可以，`小说.科幻.硬科幻` 不行 |
| 每级 ≤24 字 | 太长会拒绝保存 |
| 每级不能含标点/空格/下划线 | 正则 `^[^\W_]+$`（中日韩文字、字母、数字可以） |
| 留空或填「清除」「clear」 | 表示归到根目录 |

## 怎么批量设置

单个点标签太慢时，用整本书列表的批量编辑：

1. 管理 → 书籍管理
2. 勾选多本书 → 批量编辑 → 目录字段
3. 或者用 `tools/category_backfill.py`（按 calibre 里已有的类别自动推导目录）

## 为什么有些书「自动就有目录值」

不是误操作。目录是 calibre 的 `#folder` 自定义列，以下动作都会写入它：

- 导入时 `tools/category_backfill.py` 按规则从类别推导
- 批量编辑时一次写多本
- 从别的库同步/恢复元数据

想清掉：详情页点标签 → 输入「清除」→ 保存。

## 和「丛书」（series）的区别

| | 目录 | 丛书 |
|---|---|---|
| 结构 | 最多 2 级的树 | 平铺的序列名 + 序号 |
| 一本书 | 只能属于一个目录 | 只能属于一个丛书 |
| 用途 | 自定义分类（题材/来源/语种…） | 出版顺序（如「哈利·波特 #7」） |
| 排序 | 按名字 | 按序号 |

两者可以同时用。哈利·波特这套书典型做法：丛书填「哈利·波特」，序号 7；
目录填「小说.奇幻」。

## 常见问题

**改了配置没生效**
`ENABLE_FOLDER_BROWSE` 是后端启动时读的，改完必须重启 tornado，光刷新浏览器不够。

**侧栏勾了「目录」还是不显示**
先看总开关有没有开。总开关关着时，侧栏的勾选不生效。

**保存目录报「目录名无效」**
检查是不是超过 2 级、或者某一级里有书名号、括号、空格、下划线。

**目录里的书数量是 0，但书确实设了目录**
改目录后 calibre 的缓存索引要重建，等一下或重启 tornado。
