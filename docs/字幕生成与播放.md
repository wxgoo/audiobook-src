# 字幕生成与播放工作流

> 结论：**播放器字幕显示上游已内置，不需要改代码**。缺的只是 `.srt` 文件本身，
> 由 `srt-tool/`（PC 上跑）生成，SMB 拷进 NAS 即可。
>
> `srt-tool` 当前版本 **v1.2.0**：新增图形界面 `make_srt_gui.exe`，双击即用；
> 识别内核与命令行版共用（`srt_core.py`），结果、缓存、参数含义完全一致。
>
> **build.22 起工具箱新增「音频转写文稿」卡片**：选书直接在 NAS 上转写
> `.audio/` 里的音频（同一识别内核），生成后播放器自动加载——不想在 PC 上
> 跑的可以直接用网页工具箱入口（依赖容器内 faster-whisper，见 requirements-optional.txt）。

## 全流程

```
PC: make_srt_gui / make_srt 生成 .srt ──SMB──▶ NAS: audiobook-data/books/audios/<book_id>/ ──▶ 网页播放器同步显示
```

### ① PC 上生成字幕

**图形界面（v1.2.0 起，推荐日常用）**

双击 `dist\make_srt\make_srt_gui.exe`（或 `python make_srt_gui.py`）：

1. 「选目录…」选整个有声书目录（含子目录），或「选音频文件…」只处理单个文件；
   也可以直接把文件夹拖到 exe 图标上
2. 模型默认 `base`；**中文书必须把语言选成 `zh`**，否则引导语不生效
3. 点「开始生成」——进度条 + 实时日志，随时可点「停止」（当前小段识别完即中断，
   已完成文件的字幕不受影响）
4. 上次选的路径和参数会记住，下次打开不用重选

已有同名 `.srt` 的文件自动跳过，勾「已有 .srt 也重做」可强制重做。

**命令行（给脚本/批处理用）**

```sh
pip3 install faster-whisper
export HF_ENDPOINT=https://hf-mirror.com   # 连不上 huggingface 时必需

python3 make_srt.py <音频目录> --lang zh --model small --dry-run  # 先看清单
python3 make_srt.py <音频目录> --lang zh --model small            # 正式跑
```

- 字幕输出为「同目录同名 .srt」，UTF-8
- 详细参数、GUI 与命令行参数对照表、性能参考见 `srt-tool/README.md`

**v1.1 起识别策略有变化**，影响字幕质量的两个默认值：

| 参数 | 默认 | 说明 |
|---|---|---|
| `condition_on_previous_text` | **关** | 把前文喂回模型是幻觉复读的最大来源，关掉又快又稳；要旧行为加 `--condition-previous` |
| 碎段合并 | **开** | VAD 切碎的相邻小段自动合并成可读字幕；不需要加 `--no-merge` |

### ② 拷进 NAS

SMB（`\\10.140.81.11\docker`）把 `.srt` 和音频放同一个目录：

```
audiobook-data/books/audios/<book_id>/0001_第一章.mp3
audiobook-data/books/audios/<book_id>/0001_第一章.srt   ← 同目录同名
```

> `.srt` 是几百 KB 的文本，SMB 拷贝零负担。**不要在 NAS 上跑识别**——
> C2538 跑 1 小时音频要 1-3 小时（base），还拖累听书服务。

### ③ 网页端使用

打开书 → 有声书播放器：右侧字幕面板随播放滚动高亮，**点击任意一句字幕跳到对应进度**；
顶栏字幕按钮可开关（偏好会记住）。

> 详情页那个有声书弹窗已于 4.6.0-19-r13 下线（见 `上游跟进清单.md` #C11），
> 现在字幕只有播放页这一处渲染。

## 实现说明（本仓库内已具备的能力）

| 环节 | 位置 |
|---|---|
| 音频列表附字幕 URL | `webserver/handlers/audio.py` `AudioDetail.get`（扫描同目录同名 `.srt/.vtt`） |
| 字幕文件下发 | 同文件 `AudioFile.get`（content-type 含 `application/x-subrip`） |
| 播放页渲染 | `app/src/pages/audio/_id.vue`（`loadSubtitle` / `parseSRT` / 点击跳转） |

## 常见问题

| 现象 | 处理 |
|---|---|
| 播放器没有字幕按钮 | 该音频同目录没有同名 `.srt`，检查文件名是否完全一致（含序号前缀） |
| 字幕是繁体/无标点 | srt-tool 的中文引导语只在 `--lang zh` 时生效，别用 `--lang auto`（GUI 里语言要选「zh」） |
| 字幕碎成一条几个字 | 关掉了碎段合并。去掉 `--no-merge`，或调小 GUI 的「合并最大间隔」 |
| 同一句反复出现 | 关掉「喂回上文上下文」（`--condition-previous`）；v1.1 起该选项已默认关闭 |
| 双击 exe 一闪而过 | 用 `make_srt_gui.exe`（v1.2.0 新增），不要用命令行版 `make_srt.exe` |
| GUI 卡住不动、没进度 | 首次运行要下载模型（几百 MB），看日志区；连不上 HF 时设 `HF_ENDPOINT` |
| 字幕整体错位 | 音频文件更新过但 `.srt` 是旧的，重新生成（缓存键含文件 mtime，会自动重识别） |
| PC 上模型下载失败 | 设 `HF_ENDPOINT=https://hf-mirror.com` 后重跑 |
