# 权限判定对照表（r45，移除读者组后）

本表是 r45「移除读者组定制层 + 统一权限判定」的验收依据：覆盖保留的 5 套权限机制 ×
典型场景，逐格写预期。修改权限代码后，按此表逐格验证（单测 + 容器实测）。

## 背景：从 6 套到 5 套

| 机制 | r44（改前） | r45（改后） | 判定入口 |
|---|---|---|---|
| 管理员豁免 | 散落 74 处 | **收口到 `AccessControl.is_admin()`**（BaseHandler 转调，调用点不改） | `webserver/services/access_control.py` |
| 阅读范围 | `effective_limits()` 读组配置（119 处） | **直读用户字段，与上游 4.7.0 逐行等价** | `base._book_matches_limits()` / `AccessControl.reading_range_of()` |
| 操作权限位 | `Reader.can_*()` | 不变（已是模型方法） | `webserver/models.py` |
| 访客/分享 | `BookAccessService` | 不变（已是门面），re-export 到 AccessControl | `webserver/services/book_access_service.py` |
| 模块门控 | `modules` + `ModuleGateMixin` | 不变（已是门面/装饰器），re-export 到 AccessControl | `webserver/base/modules.py` |

移除的定制：`READER_GROUPS` / `READER_GROUPS_ENABLED` / `READER_GROUP_STRICT` 三个设置键、
`services/reader_group.py` + `handlers/reader_group.py` + `ReaderGroupEditor.vue`、
17 套预置模板、`Reader.extra["reader_group"]` 成员归属、`effective_limits()` 回退逻辑。
**保留**：每个用户的 `read_limit/limit_tags/limit_categories` 字段与 `ALLOW_READ_RANGE_SETTING`
全局开关（这些上游 4.7.0 也有）。

## 场景 × 预期矩阵

### ① 管理员豁免

| 场景 | 预期 | 回归测试 |
|---|---|---|
| 管理员访问任意书籍详情 | 全可见，按钮不灰 | `test_is_admin_handles_all_cases` |
| 管理员打开分类/标签树 | 不过滤，看到全库 | `test_admin_with_range_setting_keeps_all` |
| 管理员统计页 | 不被 `is_library_restricted` 拦 | `test_is_library_restricted_respects_global_switch` |
| 运维 superuser（admin_user） | 等同管理员 | `test_is_admin_handles_all_cases` |
| 匿名访客 | 非管理员 | 同上 |

### ② 阅读范围（read_limit: 0 不限 / 1 白名单 / 2 黑名单）

| 场景 | 预期 | 回归测试 |
|---|---|---|
| 全局开关关闭 + 用户 read_limit=1 | 全库可见；统计页**不隐藏** | `test_is_library_restricted_respects_global_switch` |
| 白名单只填标签「太空」 | 只见命中标签的书；tab count 与列表 total 同步削减 | `test_restricted_user_counts_shrink_together` |
| 白名单只填分类「历史」 | 分类列表只剩「历史」 | `test_whitelist_filters_by_name` |
| 黑名单填分类「科幻」 | 分类列表去掉「科幻」 | `test_blacklist_removes_by_name` |
| 白名单**空条件** | 一本书都看不到（严格语义，比上游更严谨） | `_book_matches_limits` 单测 |
| 黑名单**空条件** | 全库可读（不屏蔽任何书） | 同上 |
| 分类与标签同时填 | 「或」关系，命中任一即可见 | 同上 |
| 匿名访客 + 开关开启 | 只见无标签且无分类的书 | `test_guest_sees_only_unrestricted_books` |
| 用户自身字段（迁移后） | 与迁移前「组继承的生效值」一致 | `test_migrate_reader_group.py` 全组 |

### ③ 操作权限位（Reader.can_*）

| 场景 | 预期 | 说明 |
|---|---|---|
| permission 含小写 `r` | 可读 | `has_permission` 原语义不变 |
| permission 含大写 `R` | 禁止读 | 同上 |
| 两者都没有 | 用 default | 同上 |
| 管理员 | 绕过操作位限制 | 走 `AccessControl.is_admin` |

### ④ 访客 / 分享（BookAccessService）

| 场景 | 预期 | 回归测试 |
|---|---|---|

| 有效分享链接 + REQUIRE_LOGIN | 分享优先，持授权可读 | 同上 |
| ENABLE_SHARE_LINK 关闭 | 已发分享链接一并失效 | 同上 |
| 公开书单 guest_read | 开关关闭时失效 | 同上 |

### ⑤ 模块门控（modules + ModuleGateMixin）

| 场景 | 预期 | 回归测试 |
|---|---|---|
| 关掉有声书模块 → 入口 | 前端入口消失（`moduleOn`） | `test_module_gate_wiring.py` |

## 顺手修的口径不一致（B3）

| 问题 | 修法 | 回归测试 |
|---|---|---|
| `is_library_restricted` 未检查 `ALLOW_READ_RANGE_SETTING` 全局开关：开关关闭时把实际能看全库的用户误判受限、错误隐藏统计页 | 加 `if not CONF.get(ALLOW_READ_RANGE_SETTING): return False`，与 `is_book_visible` 同前提 | `test_is_library_restricted_respects_global_switch` |
