# 支持的图书格式

MyReader（本项目）底层使用 Calibre 管理书库，网页阅读器在 Calibre 之上提供多种格式的在线阅读。
本文说明哪些格式可以入库、哪些能在网页直接打开，以及「docx 改转 EPUB」「新增格式」背后的转换机制。

> 适用版本：4.6.0-build.27-r10 及以后。

## 一、可入库（被书库管理 / 上传 / 扫描）的格式

以下格式均可正常入库，参与搜索、分类、标签、目录与统计：

| 类别 | 格式 |
|------|------|
| 电子书 | `azw3` `epub` `mobi` `pdf` `txt` `azw` `docx` `fb2` `lit` `pdb` `prc` `rb` `snb` `tcr` `lrf` `rtf` `odt` `html` `htm` `azw1` `tpz` |
| 扫描版 / 漫画 | `djvu` `uvz` `cbz` |

合计 **24 种**（电子书 21 + 扫描 3）。

## 二、网页在线阅读支持情况

| 格式 | 网页直接读 | 阅读方式 |
|------|-----------|---------|
| `epub` | ✅ 原生 | MyReader / epub.js 内嵌 |
| `pdf` | ✅ 原生 | PDF.js 内嵌（需下载权限）|
| `fb2` | ✅ 原生 | MyReader 内嵌（仅 MyReader 阅读器模式，见第五节）|
| `cbz` | ✅ 原生 | MyReader 内嵌（漫画；仅 MyReader 模式）|
| `djvu` | ✅ 原生 | DjVu.js 内嵌（需下载权限）|
| `txt` | ✅ 专用 | 纯文本阅读器 |
| `mobi` / `azw` / `azw3` | ⚠️ 自动转 EPUB | 打开时后台转 EPUB 后读 |
| `docx` | ⚠️ 自动转 EPUB | 打开时后台转 EPUB 后读（**旧版为转 PDF，现统一改转 EPUB**）|
| `lit` `pdb` `prc` `rb` `snb` `tcr` `lrf` `rtf` `odt` `html` `htm` `azw1` `tpz` | ⚠️ 自动转 EPUB | 打开时后台转 EPUB 后读 |
| `uvz` | ❌ | 仅入库，无在线阅读器 |
| 其他格式 | ❌ | 提示「暂不支持，请转 EPUB 或 PDF 后阅读」|

## 三、docx 的处理（重要变更）

- **旧行为**：打开一本只有 `docx` 的书时，后端自动把它转成 **PDF**，再用 PDF 阅读器打开。PDF 是分页扫描式，不能重排、不能全文搜索，阅读体验差。
- **新行为**：`docx` 现在与 `mobi` / `azw3` 等其他电子书一致，**自动转成 EPUB**，交给流式阅读器打开，支持重排、全文搜索、字号调整。
- 优先级：若书本身已带 `epub` 格式，直接读 epub，不触发转换；若书同时有 `docx` 和 `pdf`，现在优先转 `docx → epub`（而非读 PDF）。
- 把书推送到 **KOReader 实体设备**时，`docx` 仍可直接在设备端阅读（KOReader 自身支持），只有「网页在线阅读」走上述转 EPUB 逻辑。

## 四、新增格式（lit / pdb / rtf / odt / html …）如何工作

- 这些格式由 Calibre 的 `ebook-convert` 原生支持作为输入，无需额外软件依赖。
- 打开这类书时，系统在后台调用 `ebook-convert <源文件> <epub>` 生成 EPUB，再交给网页 EPUB 阅读器；转换完成后该书会新增一个 `epub` 格式，后续直接读 epub，不再重复转换。
- 转换质量取决于源文件排版：纯文本 / 标准文档（`html`、`odt`、`rtf`、`txt`）效果最好；老旧专有格式（`lit`、`pdb`、`lrf` 等）可能丢失部分样式，但正文可读。
- 转换超时可在「设置 → 转换超时」中调大（默认 3 分钟）。

## 五、阅读器模式注意

系统设置中的「EPUB 阅读器」(`EPUB_VIEWER`) 可选择 **MyReader**（默认）或 **epub.js**：

- **MyReader 模式**（默认）：原生支持 `epub` / `pdf` / `cbz` / `fb2`，这四种直接内嵌打开；其余格式（`docx`、`mobi`、第三节/第四节中的新增格式）转 EPUB 后用 epub.js 渲染。
- **epub.js 模式**：`fb2` / `cbz` 这类仅 MyReader 原生支持的格式将无法直接在线阅读（`djvu` / `pdf` 仍有专用阅读器）。

## 六、限制

- `uvz` 仅入库不可读（无对应在线阅读器）。
- 在线阅读依赖系统已安装 Calibre（`ebook-convert`）；未安装或转换失败时，对应格式会提示「暂不支持，请转 EPUB 或 PDF 后阅读」。
- 漫画 `cbr` / `cbc` 等需要非自由解压组件，暂未纳入白名单。
- 自动转换只生成阅读所需的中间 EPUB，不会修改或删除你的原始格式文件。
