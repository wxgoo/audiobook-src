## 3. 推荐执行顺序

1. 读 `docs/交付/应用与回滚.md`，在目标仓库按 `01 → 14` 应用（或只取所需组合）。
2. 按「最小验证」跑语法检查与 14 条单测。
3. NAS 上按 `docs/交付/NAS备份演练清单.md` 用**独立演练目录**跑通备份 → 再切正式目录与 cron。
4. 上线后按 `docs/优化实施与决策记录.md` 的「发布说明 / 验收命令」冒烟。
5. 上游跟进用 `python3 scripts/upstream/patch_tool.py status --upstream <上游检出>` 复核。
