# 上传到 NAS 怎么放

两个包，作用不同：

| 文件 | 大小 | md5 | 干什么 |
|---|---|---|---|
| `audiobook-deploy-4.6.0-10.tar.gz` | 198M | `55b02fb4bd018a68a084ef85a5e71ef1` | **主包**，升级用 |
| `audiobook-docs-scripts-4.6.0-10.tar.gz` | 74K | `e52f2b364f480143d6a38f9c1d235425` | 只含文档 + 脚本，方便先看 |

小包里的文件是直接从主包解出来的副本，不会有两边不一致的问题。
**升级只需要主包**，小包是给你提前翻阅文档用的，看不看都不影响。

> 主包已于 16:20 瘦身重做：去掉 `scripts/archive/`、`docs/archive/`、
> `docs/settings-redesign/` 和 `audiobook-src/`（历史脚本、旧版手册、设计稿截图、
> 一个空的嵌套仓库条目）。这些**只留在源码仓库**，NAS 上用不到。
> 之前拿到的 `a027…` / `7861…` / `111f…` 三个同版本号旧包全部作废。
>
> 解开后 `scripts/` 里应该正好这 7 个文件、`docs/` 里正好 3 个 `.md`：
>
> ```
> scripts/  check-reader.sh deploy.sh pack.sh protect-custom.sh
>           README.md upgrade.sh upgrade-upstream.sh
> docs/     操作总纲.md 移植改动清单.md 部署包说明.md
> ```
>
> 多出 `archive/` 之类就意味着拿错了包，先用
> `sh audiobook/scripts/pack.sh --check <包路径>` 自检一遍。

## 一、传文件

两个包都放到 `/volume1/docker/`（File Station 拖进去即可）。

---

## 二、删掉根目录那 8 个旧脚本（**别省这步**）

SSH 登录 NAS：

```sh
cd /volume1/docker
rm -f check-reader.sh deploy.sh export-myreader.sh merge-4.6.0-9.sh \
      protect-custom.sh rollback-to-8.sh upgrade.sh upgrade-upstream.sh
```

**为什么必须删**：旧 `deploy.sh` 靠数符号链接总数判断产物完整性，
数的是「链接条数」而不是「链接能不能指到东西」，等于没验。
另外旧版 8 个脚本散在根目录，和新的 `scripts/` 混着放，很容易跑错版本。
新版已改成查有效链接数，并且只认 `scripts/` 下这一份。

## 三、升级

```sh
cd /volume1/docker
md5sum audiobook-deploy-4.6.0-10.tar.gz   # 应为 55b02fb4bd018a68a084ef85a5e71ef1
tar -xzf audiobook-deploy-4.6.0-10.tar.gz
sh audiobook/scripts/upgrade.sh /volume1/docker/audiobook-deploy-4.6.0-10.tar.gz
```

约 4 分钟。脚本会：备份数据库 → 停容器 → 旧源码改名 → 解压新源码 →
校验 → 构建 → 启动 → 验证 4 个进程。

**注意路径变了**：`upgrade.sh` 现在在 `audiobook/scripts/` 下，不在根目录。

## 四、验证

```sh
# 1. 四个进程都该是 RUNNING
docker exec audiobook-mybooks-1 supervisorctl status

# 2. 阅读器能起来（这是本次重点检查项）
sh audiobook/scripts/check-reader.sh

# 3. 浏览器打开 http://<NAS_IP>:9800，Ctrl+F5 强刷
```

`check-reader.sh` 是只读的，不改任何东西，随时可以跑。

## 五、如果只想先看文档


## 以后出包

开发侧（沙箱）一条命令：

```sh
sh scripts/pack.sh
```

它会打包 + 自动验包。**别自己 `tar --transform`**——那会把 `myreader-dist` 里
127 个符号链接的相对路径改坏（`../../../../` 被替换成 `audiobook./../../../`），
包能解开、文件数也对，但链接全断，部署后阅读器 502。
