## 9. 维护约定

1. **一个主题一份文档**：新增内容优先补进现有文档，不再按 build 号新建。
2. **版本记录只写 `CHANGELOG.md`**：部署/运维文档只写流程，不复制版本变更。
3. **过时但有价值 → `archive/`**，不直接删；归档文件不改正文，只在文首加一行说明。
4. **`delivery/overlay/files/docs/` 只放 NAS 上要用的 5 篇**：`部署包说明.md`、`操作总纲.md`、
   `在线更新说明.md`、`备份与恢复演练.md`、`NAS-Docker缓存池重置与镜像备份恢复手册.md`，与 `docs/` 同名文件逐字节一致；
   `archive/` 不复制到 overlay。
5. overlay 的 `MANIFEST.tsv` / `SHA256SUMS` 由出包流程重算；手工改完文档后，出包前需重新生成。
6. **代码层硬约束正文只在 [`../CLAUDE.md`](../CLAUDE.md) 的「维护约定（硬约束）」**：同步 IO 不进 ioloop、会转圈的 await 必须带超时与可见失败出口、Vue 2 模板带参调用的方法必须留在 `methods`。本节只留入口，不复制正文。
