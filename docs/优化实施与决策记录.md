## 2. 发布说明

### 2.1 上线步骤（保守路径）

1. 合并/检出 `opt/p0-p1`，在构建机上重建镜像（`scripts/deploy.sh`）。
2. 备份先行：按 [备份与恢复演练](备份与恢复演练.md) 跑一次全量 `scripts/backup.sh --db-only` 与 `--files-only`。
3. 配置项按需写进 `auto.py`（defaults 已给出保守值）：
   - `ALLOW_MCP_TOKEN_IN_URL=False`
   - `AUDIO_CACHE_REFRESH_SECONDS=21600`
   - `SEARCH_INDEX_ENABLED=True`、`SEARCH_INDEX_PATH=/data/books/search_index.db`
   - `import_phase1_batch_size=500`、`import_phase2_batch_size=20`
4. 首次启动后看日志：`AudioBooksCache` 预热、`search index` 后台重建完成。
5. 冒烟：书目列表（offset 与 `after` 两种）、有声书列表、音频拖动、MCP 调用（Header token）、AI WS。

### 2.2 验收命令

```sh
# 检索
python3 scripts/search_index.py status
python3 scripts/search_index.py search 三体

# 备份
./scripts/backup.sh --list
./scripts/backup.sh --dry-run

# 单测（需要完整依赖环境）
python -m pytest tests/test_pagination.py tests/test_search_index.py \
                 tests/test_background_tasks.py tests/test_audio_books_cache.py -q

# 上游补丁
python3 scripts/upstream/patch_tool.py list
```

### 2.3 已知限制 / 未完成
